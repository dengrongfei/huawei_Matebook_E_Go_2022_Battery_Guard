电池优化（充电 + 空闲节电）
========================

独立小工具，逻辑抄华为管家「设置中心 → 电脑优化」里的充电和空闲节电。
不实现智能加速、智能省电（杀/冻进程）、系统异常修复。

充电限制只在本程序运行时生效（窗口或托盘都行）。从托盘「退出」后写成不限制（充满）。

智能充电对齐管家 SmartChargePlugin：
- 家用 40–70 / 办公 70–90 / 差旅 95–100
- 每 60 分钟再写一次 EC（timerDuration）
- 插电约 72 小时后切久插保护 40–70（acDuration，BIOS 0x1403，关机插电也算）
- 电池约 45°C 且电量 ≥70% 时切高温保护 40–70（highTemp，读电池 NTC 0x0202/0x0E，不用 CPU 热区）
- 拔插电源、睡眠唤醒时立刻再判断一次
- 0x1503 里的 0x48 就是 72 小时参数

充电走本机 ACPI WMI（不复制管家 DLL）：

  root\wmi → OemWMIMethod.OemWMIfun → 笔记本 EC
  智充 0x1503：03 15 [模式] 48 [下限] [上限]  模式 1家用 2办公 3差旅 4智能保护
  阈值 0x1003：03 10 [下限] [上限]
  插电时长 0x1403：03 14
  电池温度 0x0202：02 02 0E（传感器 0x0E = 电池 NTC）

用法
----
1. 运行 build.bat 编译
2. 双击「电池优化.exe」（UAC）
3. 关窗口进托盘，限制仍有效；托盘 → 退出 后限制取消
4. 可选开机自动启动
